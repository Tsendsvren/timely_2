# Timely - Ухаалаг оюутны төлөвлөгч ба академик удирдлагын систем

## 1. Шийдэх асуудал
Оюутнууд хичээлийн хуваарь, бие даалтын дуусах хугацаа (deadline), хичээлээс гадуурх тогтмол ажил/дадал болон дүнгээ нэгдсэн байдлаар төлөвлөх боломжгүйгээс болж цагаа зөв хуваарилж чаддаггүй. Энэхүү систем нь оюутны сул цагуудад "Study Block" санал болгох, Focus Timer-аар цаг хэмжин Gamification (оноо, аватар) ашиглан идэвхжүүлэх, мөн дүнгийн "What-if" тооцоолуураар академик зорилгодоо хүрэхэд тусална.

## 2. Хэрэглэгч ба Эрх (Roles)
- **Student (Оюутан/Гишүүн):** Төлөвлөгөө, бие даалт, дадал нэмэх, Focus Timer ажиллуулж оноо цуглуулах, Дүн ба GPA тооцоолуур ашиглах, дэлгүүрээс аватарын хувцас худалдан авах.
- **Admin (Системийн админ):** Аватарын дэлгүүрт шинэ бараа/хувцас (ShopItem) нэмэх, засах, устгах (CRUD).

## 3. Гол хэрэглэгчийн урсгал
1. Оюутан бүртгүүлж, нэвтэрнэ -> Dashboard дээр өдрийн хуваарь ба Timely аватар харна.
2. Хичээлийн хуваарь ба гадуурх ачаалал (Commitment) нэмнэ -> Бие даалт нэмэхэд систем сул цагт "Study block" санал болгоно.
3. Focus Timer эхлүүлж даалгавар хийнэ -> Бодит хугацаагаар оноо бодогдож цуглуулсан оноогоор аватарт хувцас item-ууд авна.
4. Дүнгийн "What-if" тооцоолуураар хичээлийн дүнгийн төлөвлөгөөг гаргаж, одоогийн онооны задаргааг тооцоолж, 8 улирлын GPA зорилгоо тодорхойлно.
5. Админ дэлгүүрт шинэ аватарын хувцас item нэмнэ.

## 4. Хамрах хүрээ (Scope)
- Өгөгдлийн загвар: 5 Entity (User, Task, Commitment, CourseGrade, ShopItem).
- Frontend: 12 SPA Route (React Router).
- Backend: 12 REST API Endpoint (Express + MongoDB).

## 5. Хамрахгүй хүрээ
- Сургуулийн мэдээллийн системтэй (SIS/ESIS) шууд интеграци хийхгүй.
- Төлбөрийн бодит систем болон бодит цагийн чат ажиллахгүй.

## 6. Амжилтын шалгуур
- Оюутан U01 даалгавар нэмж, таймер дуусгахад оноо нэмэгдэж, сервер restart хийсэн ч өгөгдөл хадгалагдана.
- Нэвтрээгүй эсвэл энгийн хэрэглэгч админы дэлгүүр удирдах API дуудахад сервер 401/403 буцаана.
