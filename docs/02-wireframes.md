# Дэлгэцийн ноорог (Wireframes) — Timely

Timely бол оюутны цаг төлөвлөлт, Focus Timer, дүн/GPA тооцоолуур, Gamification-ийг нэгтгэсэн MERN SPA систем юм.
Энэ баримт нь 12 SPA route бүрийн байрлал, талбар, товч, шилжилт, хоосон болон алдааны төлөвийг тодорхойлно.

- Figma: https://www.figma.com/design/W5166esKJRM8ULW1Epb2F6/web_zohiomj?t=xBt8v9c7A2MBq64c-1 (frame бүр route-ийн нэрээр нэрлэгдсэн)
- Ноорог зургууд: `./wireframes/` хавтас

## Нийтлэг дүрэм (бүх дэлгэцэд)

- **Layout:** Desktop дээр зүүн sidebar (240px) + агуулга. `/authenticate` sidebar-гүй.
- **Mobile (390px):** Sidebar нь доод цэс болно, картууд нэг баганад цуварна, хэвтээ scroll үүсэхгүй. Хүснэгт/календарь өөрийн container дотор л scroll хийнэ.
- **Loading:** Өгөгдөл ачаалж байхад skeleton харуулна, товчнууд идэвхгүй.
- **Серверийн алдаа:** Дэлгэцийн дээд хэсэгт "Алдаа гарлаа. Дахин оролдоно уу" мэдэгдэл + [Дахин оролдох] товч. Оруулсан утга устахгүй.
- **401 (токен дууссан):** `/authenticate` руу шилжүүлж "Дахин нэвтэрнэ үү" гэж харуулна.
- **403:** Оюутан `/admin/shop` руу орвол `/` руу буцаана.
- **Submit хийж байх үед:** Товч идэвхгүй болж "Хадгалж байна…" гэж харагдана.

## 2. Бүртгүүлэх / Нэвтрэх

- **Route:** `/authenticate` | **Хариуцагч:** M01 | **Эрх:** Зочин
- **Ноорог зураг:** `./wireframes/02-authenticate.png`

```
[ Hero: Timely, онцлогууд, аватар ]  |  [ Нэвтрэх | Бүртгүүлэх ]
                                     |  [Имэйл ______________________]
                                     |  [Нууц үг ____________________]
                                     |  [Намайг сана]   [Нууц үг мартсан?]
                                     |  [        Нэвтрэх        ]
```

- **Талбарууд:** Нэр (зөвхөн бүртгүүлэх), Имэйл (String), Нууц үг (String, 8+ тэмдэгт), Нууц үг давтах (зөвхөн бүртгүүлэх).
- **Үйлдэл:** [Нэвтрэх] → `POST /api/auth/login`; [Бүртгүүлэх] → `POST /api/auth/signup`. Амжилттай бол JWT хадгалж `/` руу шилжинэ.
- **Validation:** "Имэйл хаяг буруу байна", "Нууц үг 8-аас дээш тэмдэгт байна", "Нууц үг таарахгүй байна", "Нэр оруулна уу".
- **Алдаа:** "Имэйл эсвэл нууц үг буруу" (нууц үгийн талбарыг л цэвэрлэнэ); бүртгэлтэй имэйл бол "Энэ имэйл бүртгэлтэй байна".
- **Mobile:** Hero хэсэг нуугдаж зөвхөн маягт нэг баганаар харагдана.

[Гарчиг ______________________________]

## 5. Даалгавар засах & дахин төлөвлөх

- **Route:** `/tasks/:id` | **Хариуцагч:** M03 (reschedule логик: M04) | **Эрх:** Оюутан
- **Ноорог зураг:** `./wireframes/05-task-edit.png`

```
[Гарчиг ____]  [Хичээл ____]  [Deadline ____]
[Priority ___] [Төлөвлөсөн (мин) __] [Бодит (мин) __]
[Төлөв: (Хүлээгдэж буй) (Дууссан) (Шилжүүлсэн)]
[Гүйцэтгэл ▓▓▓░░ 54/90]           | Хоцорсон блокууд:
[Устгах]        [Хадгалах]        |  Пү 11:00 [Баасан][Бямба] [Шилжүүлэх] [Устгах]
```

- **Талбарууд:** Task-ийн бүх талбар (title, deadline, priority, estimatedMinutes, actualMinutes, status), хоцорсон блокийн жагсаалт.
- **Үйлдэл:** [Хадгалах] → `PUT /api/tasks/:id`; [Устгах] → баталгаажуулах цонх "Энэ даалгаврыг устгах уу?" → `DELETE`; [Шилжүүлэх] → блок сонгосон өдөр рүү шилжиж status=`rescheduled`.
- **Хоосон төлөв:** Хоцорсон блок байхгүй бол "Хоцорсон блок алга".
- **Алдаа:** Даалгавар олдохгүй (404) бол "Даалгавар олдсонгүй" + [Төлөвлөгч рүү буцах]. Сонгосон өдөр сул цаггүй бол "Тухайн өдөр сул цаг алга, өөр өдөр сонгоно уу".
- **Mobile:** Хоцорсон блокууд маягтын доор нэг баганад.

## 7. Focus Timer

- **Route:** `/focus-timer` | **Хариуцагч:** M03 | **Эрх:** Оюутан
- **Ноорог зураг:** `./wireframes/07-focus-timer.png`

```
[Даалгавар сонгох v]
          (   54:12   )      | Идэвхтэй даалгавар
        90 минутаас          | Энэ session-ий оноо: +64
[Start] [Pause] [Stop & оноо авах] | Өнөөдрийн session-ууд
```

- **Талбарууд:** Даалгавар сонгогч, таймер (мм:сс), прогресс тойрог, оноо тооцооны хэсэг, session-ий түүх.
- **Үйлдэл:** [Start] цаг эхлүүлнэ; [Pause] түр зогсооно; [Stop & оноо авах] → бодит минутыг `actualMinutes`-д бичиж `User.points` нэмнэ → `/` руу шилжинэ.
- **Хоосон төлөв:** Даалгавар байхгүй бол "Эхлээд даалгавар нэмнэ үү [Даалгавар нэмэх]". Даалгавар сонгоогүй үед [Start] идэвхгүй.
- **Алдаа:** Stop дарахад сервер амжилтгүй бол цагийг хадгалж "Оноо хадгалагдсангүй [Дахин оролдох]" гэнэ.
- **Хуудас хаах:** Таймер ажиллаж байхад гарах гэвэл "Таймер ажиллаж байна. Гарах уу?" анхааруулна.
- **Mobile:** Тойрог дэлгэцийн өргөнд тохирно, товчнууд бүтэн өргөнөөр.

- **Үйлдэл:** [Хадгалах] → `PUT /api/auth/me`; [Өмсөх]/[Тайлах] → аватар шууд шинэчлэгдэнэ; [Гарах] → токен устгаж `/authenticate`.
- **Validation:** "Одоогийн нууц үг буруу", "Шинэ нууц үг 8+ тэмдэгт".
- **Хоосон төлөв:** Худалдаж авсан зүйл байхгүй бол "Одоогоор зүйл алга [Дэлгүүр рүү очих]".
- **Mobile:** Аватар дээд талд, маягт болон жагсаалт нэг баганад.

## 12. Дэлгүүр удирдах (Админ)

- **Route:** `/admin/shop` | **Хариуцагч:** M05 | **Эрх:** Админ
- **Ноорог зураг:** `./wireframes/12-admin-shop.png`

```
[Нийт бараа 24] [Борлуулалт 312] [Идэвхтэй хэрэглэгч 86]
[Бараа | Төрөл | Үнэ | [засах][устгах] ] x N   | [Шинэ бараа нэмэх]
                                                | [Нэр] (Хувцас)(Өнгө)(Хэрэгсэл)
                                                | [Үнэ] [Зураг чирэх]  [Нэмэх]
```

- **Талбарууд:** name (String), type (clothes/color/accessory), pricePoints (Number), imageUrl, createdBy (админ).
- **Үйлдэл:** [Нэмэх] → `POST /api/shop`; [засах] → маягт утгатай; [устгах] → "Энэ барааг устгах уу?" баталгаажуулалт → `DELETE`.
- **Validation:** "Нэр оруулна уу", "Үнэ 0-ээс их байна", "Зураг сонгоно уу".
- **Хоосон төлөв:** "Бараа алга. [Шинэ бараа нэмэх]".
- **Эрх:** Оюутан орвол `/` руу буцаана (403).
- **Алдаа:** Зураг хэт том (2MB+) бол "Зураг 2MB-аас бага байна".
- **Mobile:** Хүснэгт карт хэлбэрт шилжиж, маягт доор.
